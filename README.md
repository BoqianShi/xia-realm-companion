# 侠界之旅 · 行侠手记

[![Checks](https://github.com/BoqianShi/xia-realm-companion/actions/workflows/checks.yml/badge.svg)](https://github.com/BoqianShi/xia-realm-companion/actions/workflows/checks.yml)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](LICENSE)

面向线下武侠跑团的共享角色卡与主持助手。玩家用手机查看招式、记录资源，主持人用电脑准备场景与先攻，并可将公开信息投到大屏。

**本仓库公开程序、规则计算实现和原创演示资料，不分发《侠界之旅》规则书、官方模组正文、扫描图片、官方 NPC/预生成卡数据库或任何实际团存档。** 默认的「雨亭旅人」「雨亭试手」是项目原创功能示例，不是官方角色、模组或平衡性建议。本项目非官方，与规则著作权人无隶属关系。

## 已有功能

- **角色卡**：资源、属性、技能、架招、状态、行囊、笔记；武学整套收藏、逐招折叠，显示阶段、消耗、效果和计算依据。
- **构筑与成长**：建卡引导、独立试配、内功切换、逐招修炼、游戏内修炼日和经脉记录；资料搜索筛选。
- **桌边记录**：手动记资源、状态层数、持续时间和计数器；版本检查、请求去重、可安全撤销的记录。
- **主持助手**：模组正文、NPC、遭遇、关联场次笔记；先攻自动掷 D20 并排序，默认整轮推进，也可指定行动者。
- **大屏**：显示明确公开的资源、架招和效果；支持上传头像。投屏范围不等于访问权限。
- **数据带走**：角色/本团 JSON 导出恢复；A4 打印与浏览器“另存为 PDF”；最近资料离线查看、本机草稿。

除先攻外，掷骰在线下完成。记录状态、条件试算和推进轮次不自动扣资源、不结算目标、不递减持续时间。

## 本地启动

需要 **Node.js 22.18+** 和 npm；首次安装需要联网。

```sh
git clone https://github.com/BoqianShi/xia-realm-companion.git
cd xia-realm-companion
npm ci
npm run db:local
npm run dev
```

打开 <http://localhost:5185>。建立角色时选择“用入门示范开始”；主持人视图可添加《雨亭试手》并载入练习遭遇。安装会准备原创资料包，本地数据库和自行导入的内容均被 Git 忽略。

```sh
npm run typecheck
npm test
npm run build
npm start
```

`npm start` 运行构建后的本地 Worker，与开发服务使用同一默认本地 D1 存储；首次仍需数据库迁移，不要让两个服务同时占用 5185 端口。
