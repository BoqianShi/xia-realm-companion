# 结构与边界

| 目录 | 职责 |
| --- | --- |
| `app/`, `components/` | 角色卡、主持台、大屏、打印 |
| `lib/catalog.ts`, `lib/content-pack.ts` | 内容与学习关系 |
| `lib/rules.ts`, `move-*`, `reference-*` | 计算、条件试算、展示 |
| `lib/tabletop.ts`, `growth.ts` | 手动记账、成长 |
| `lib/hosting.ts`, `host-*` | 先攻、投屏、主持上下文 |
| `lib/campaign.ts`, `validation.ts`, `db/` | 命令、版本控制、去重、共享保存 |
| `content/` | 仅原创演示 |
| `scripts/`, `tests/` | 内容准备、发布检查、回归 |

D1 的 `campaigns` 保存默认团 `default`。命令检查共享版本和角色/主持台版本，数据库条件更新防止并发覆盖。重复 request ID 返回已保存结果；离线草稿不自动重放写入。

源目录没有真实团的数据库种子。示范仅在点击时加入建卡草稿，浏览页面不自动建立角色。

计算仍包含侠界专属属性、技能、动作与部分条目 ID 分支；换资料包不等于通用 TRPG 引擎。新效果需维护计算和展示路径；未实现部分明确留给桌上处理。

首屏按使用频率排列：资源、属性、招式、技能、行囊优先。规则帮助是辅助入口，五声音阶仅在相关演奏场景出现，不把最近功能默认置顶。

先攻自动掷骰，默认手动整轮推进。状态、气血、架招只记录；其他检定在线下完成。条件试算只读，不借用遗留战斗接口自动记账。
